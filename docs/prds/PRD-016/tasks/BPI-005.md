# BPI-005 — Align the deterministic simulator

Status: Done
Review Mode: Agent
Review Reason: Simulator time, state, history, reset, and strict response shapes
are deterministic through manually advanced tests.

## Goal

Remove prediction behavior from the device simulator and emit the new
controller diagnostics without implying firmware timing or physical safety.

## Scope

- Remove prediction query handling, forecast generation, model/fallback data,
  and prediction-specific simulator tests.
- Keep API v1 and queryless API v2 ordinary behavior unchanged.
- Emit bounded, deterministic controller-history diagnostics matching BPI-001.
- Preserve manually advanced time, reset/power-cycle semantics, history paging,
  extraction/cooldown behavior, and strict parsing.
- Update simulator README and integration fixtures.

## Non-Scope

- Reproducing firmware PI thermodynamics, sensor/GPIO faults, scheduler timing,
  SSR switching, mobile persistence, or physical validation.

## Implementation Plan

1. Trace simulator prediction query/state/history behavior.
2. Remove prediction-only code and tests.
3. Add deterministic controller diagnostic samples consistent with simulator
   command state.
4. Update strict route and history tests, including rejection of removed fields.
5. Run simulator tests and typecheck.

## Acceptance Criteria

- [x] Simulator exposes no prediction query or prediction-specific state.
- [x] API v1 and queryless API v2 ordinary workflows remain compatible.
- [x] History uses the new strict controller diagnostic shape and eight-sample
  page maximum.
- [x] Reset, power-cycle, paging, extraction, cooldown, and manual-time behavior
  remain deterministic.
- [x] Simulator tests and typecheck pass.

## Completion Evidence

- `/api/v2/state` now rejects every query parameter, including the removed
  `include=prediction` opt-in, while queryless v2 and API v1 remain unchanged.
- History emits a strict legacy-controller configuration and bounded,
  deterministic controller diagnostics. Deliberately impossible simulator
  control temperatures are clamped only in diagnostic telemetry, without
  changing the independently reported logical state used by workflow tests.
- PASS — 77 simulator tests / 556 expectations and TypeScript typecheck.
